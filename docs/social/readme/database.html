Zyvor·MachinaController database

Start on SQLite. Grow into PostgreSQL.

DEFAULT

SQLite

  • Embedded, one file, zero setup
  • Best for 1 or 2 hosts and evaluations
  • One writer, one controller
DATABASE_URL=sqlite:///var/lib/machina/controller.db
machinactl db setup→--migrate copies your rows←setup sqlite is the way back
LARGE FLEETS

PostgreSQL

  • Hundreds of machines, no single-writer limit
  • Several controllers share one state store
  • Leader election with hand-over inside the lease
machinactl db setup pod | package | external --url postgres://…
One source tree, chosen at build time: every schema change ships twice (SQLite and PostgreSQL migrations), and CI prepares every SQL statement against PostgreSQL. A managed Postgres pod, daily dumps, machinactl db status|backup|restore and the machina-dbtool importer are included.
