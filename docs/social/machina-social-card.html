The private cloud you can install before lunch. VMs, consoles, fleet HA and AI operations from three Rust binaries, with no OpenStack-sized service sprawl.

INSTALL1

One command

machinactl deploy on any Linux host with KVM. Embedded SQLite, no database cluster.

RUN2

VMs on day one

Create, snapshot, back up and clone. Cloud-init, GPU passthrough, golden images.

CONSOLE3

In the browser

noVNC, SPICE, serial and SSH proxied by the daemon. No separate gateway.

FLEET4

Scale out

A gRPC agent per host. HA failover, DRS balancing and live migration.

OPERATE5

Zyra AI on call

Diagnoses incidents, proposes the fix and waits for your approval.
